# Japanese — Japan

## Audience and conventions

Use native sentence order and established UI and crypto vocabulary. アクティビティ, ステーキング, and 紹介コード are normal terms, not machine-translation errors. Check whether copy is a button, heading, state, or explanation before choosing its form.

Subjects and possessives are commonly implicit: あなたのポジション → ポジション. Keep 自分だけ or このウォレット where they clarify exclusive control or ownership. Preserve grammatically needed wording and politeness; ご is not a possessive to delete. First-person responsibility statements and 私の紹介リンク in shared text can need explicit actors.

## Approved terminology

| Context | Wording / constraint |
|---|---|
| Redelegate, app and notifications | 再ステーキング; do not use 再委任; explanations still describe changing validator |
| Invitation rewards and points | ポイント; do not alternate with 報酬, 特典, or ボーナス |
| Earn / redeem points | ポイントを獲得 / ポイントを交換 |
| Staking rewards | 報酬 / ステーキング報酬 |
| Referral code | 紹介コード |
| Button opening code entry | 紹介コードを使う, eight characters |

## Compact labels

Chart hour/month: `1時`, `1月`. Keep these two-character labels. Other controls need their own fit check.
