# Simplified Chinese — mainland China

## Audience and conventions

Use mainland Chinese UI wording and natural sentence order. Omit unnecessary 你／你的／您／您的 when context supplies the actor: 您的余额不足 → 余额不足. Preserve explicit ownership or use 自己／本人 where needed for security, self-referral, or responsibility. Do not apply these word choices to Taiwan through character conversion.

## Approved terminology

| Context | Wording / constraint |
|---|---|
| Redelegate | 重新质押 |
| Referral / invitation; code | 邀请；邀请码 |
| Redeem code button | 兑换邀请码 |
| Invitation rewards and points | 积分 throughout headings, notifications, errors, and status |
| Earn / redeem points | 赚取积分 / 兑换积分; redemption must not say 获得积分 |
| Staking rewards | 质押奖励 / 奖励 |
| Generic Recommended | 推荐 |
| Price impact title | 价格影响 |
| TikTok | 海外抖音 |

## Compact labels

Chart periods: `1时`, `1天`, `1周`, `1月`, `1年`. Keep each two characters without spaces. Other controls need their own fit check.
