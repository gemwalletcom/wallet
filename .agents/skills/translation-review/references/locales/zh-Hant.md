# Traditional Chinese — Taiwan

## Audience and conventions

This project targets Taiwan for `zh-Hant`; the script itself does not define a region. Prefer native UI wording such as 設定、裝置、使用者、連結、身分驗證、存取、啟用／停用. Use these by context, not global replacement. Shared Chinese financial terms are not automatically errors.

Omit unnecessary 你／您／您的: 您的錢包已準備就緒 → 錢包已準備就緒. Keep ownership and responsibility explicit where needed. Use Taiwan grammar and vocabulary rather than converting mainland copy character by character.

## Approved terminology

| Context | Wording / constraint |
|---|---|
| Redelegate | 重新質押 |
| Referral / invitation; code | 邀請；邀請碼 |
| Redeem code button | 兌換邀請碼 |
| Invitation rewards and points | 積分 throughout headings, notifications, errors, and status |
| Earn / redeem points | 賺取積分 / 兌換積分; redemption must not say 獲得積分 |
| Staking rewards | 質押獎勵 / 獎勵 |
| Generic Recommended | 推薦 |
| Price impact title | 價格影響 |
| TikTok | Tiktok; do not use 海外抖音 |

## Compact labels

Chart periods: `1時`, `1天`, `1週`, `1月`, `1年`. Keep each two characters without spaces. Other controls need their own fit check.
