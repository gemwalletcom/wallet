## Fast Test Loop

For package changes, use `just ios test-package <Package>` from the repo root (for example, `just ios test-package Assets`). This runs `<Package>Tests` through the existing app test plan. Use `just ios test <TestTarget>` for other target names and `just ios check-test Primitives` for host-compatible packages. See [Testing](skills/testing.md) for test registration and [Quality Checks](../skills/quality-checks.md) for closing checks.
