# Cross-Platform Awareness

Applies to every task. Both apps depend on the same Rust core and must stay aligned on shared product behavior; these rules say when a change in one place obliges a change elsewhere.

## Rules

1. Regenerate and verify the apps only when a `core/` change affects UniFFI/TypeShare interfaces, generated models, platform build inputs, or app-side integration:
   ```bash
   just generate
   just ios build
   just android build
   ```
   Internal Core implementation changes that preserve these contracts require relevant Core builds and tests, not iOS or Android builds. A passing Rust build is insufficient only when the change can affect app compilation or integration. Adding a variant to a TypeShare enum the apps switch over (for example `SwapProvider` or `ChainType`) is an interface change: regenerate, then handle the new case in every exhaustive Swift and Kotlin switch on both platforms. If a regeneration's effect on either app is unclear, stop and restate before adding more changes.
2. Implement parity or surface the gap. If a user-facing change should exist on both platforms, either implement both sides in the same task, or state the parity gap explicitly so it is not silently dropped.
3. Never edit generated files directly. Files marked `Generated by typeshare` come from `core/` — change the source, regenerate, and commit the regenerated output when that generated area is tracked. Generated file locations:
   - **iOS**: `Packages/Primitives/Sources/Generated/` (TypeShare models), `Packages/Gemstone/Sources/Gemstone/Gemstone.swift` and `Packages/Gemstone/Sources/GemstoneFFI/include/GemstoneFFI.h` (local ignored UniFFI bindings)
   - **Android**: `gemcore/src/main/kotlin/com/wallet/core/primitives/generated/` (TypeShare models), `core/gemstone/android/gemstone/src/main/java/uniffi/` (local ignored UniFFI bindings, generated by the `:gemstone` Gradle module at build time)
   - **Pattern**: any file with a `// Generated by typeshare` header or under `uniffi/gemstone/`
4. Run `just localize` when changing shared localization inputs. Hardcoded user-visible strings on either platform are a bug.
5. Read chain capabilities from core's `ChainConfig` (`core/crates/primitives/src/chain_config.rs`). Hand-written per-chain capability lists in app code are forbidden — they drift from core.
